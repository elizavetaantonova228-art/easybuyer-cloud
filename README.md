# EasyBuyer Cloud

Бот публикует 4 заранее подготовленных поста в Telegram каждый день: 09:00, 12:30, 16:00, 19:30 по Europe/Moscow.

## Файлы
- `bot.py` — программа
- `requirements.txt` — зависимости
- `.env.example` — пример настроек (без секретов)

## Настройки окружения
Задайте в панели хостинга (не в публичном Git):
- `TELEGRAM_BOT_TOKEN` — токен из BotFather
- `TELEGRAM_CHANNEL_ID` — `@easybuyerpz`
- `TIMEZONE` — `Europe/Moscow`

## Команды
- `python bot.py preview` — показать пример, ничего не отправлять
- `python bot.py check` — проверить Telegram
- `python bot.py publish` — ОПУБЛИКОВАТЬ один пост сразу
- `python bot.py run` — включить планировщик (долгоживущий процесс)

Важно: бесплатный хостинг должен поддерживать непрерывно работающий Python-процесс и APScheduler. Если процесс засыпает, публикации не выполняются. История публикаций сохраняется в `posted_state.json`; при пересоздании контейнера она может сброситься.

Перед включением облачного расписания остановите расписание на Mac (Control+C). Не запускайте одновременно два экземпляра бота.
